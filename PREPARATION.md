# Overview

This is a prompt to set up a "Loop" process using an LLM.
To understand what Loop Engineering is and the necessary components, please visit https://addyosmani.com/blog/loop-engineering/.

1. Create skills to analyze and update the vault during Loop process, including:
- Reviewing and updating the PRD (`Loop/PRD.md`).
- Generating goals (`Loop/GOAL.md`) from the PRD.
- Creating tasks based on approved issues and default settings.
- Creating new issues.
- Executing tasks and implementing code.
- Writing Progress.
- And other necessary skills.
Check `LOOP.md` to anticipate which skills will be required during execution.

2. Generate the initial PRD and GOAL using `IDEA.md`.

# Goal

- The role of each path within the vault is clearly defined, and skills are assigned accordingly.
- There are no unused folders within the vault.
- No skills are missing from the actual loop execution, and there are no unused skills.
